==================================================
ИНСТРУКЦИЯ ПО ЗАПУСКУ TELEGRAM-БОТА ДЛЯ ЗАПИСИ
==================================================

1. УСТАНОВКА PYTHON И ЗАВИСИМОСТЕЙ
- Убедитесь, что у вас установлен Python 3.9 или выше.
- Откройте терминал (командную строку) в папке с ботом и выполните:
  pip install -r requirements.txt

2. НАСТРОЙКА ТОКЕНА И ID АДМИНИСТРАТОРА
- Откройте файл bot.py в любом текстовом редакторе (Блокнот, VS Code).
- В строке BOT_TOKEN замените "ВАШ_ТОКЕН_ОТ_BOTFATHER" на токен вашего бота от @BotFather.
- В строке ADMIN_ID замените 123456789 на ваш личный Telegram ID (узнать его можно у бота @userinfobot).
- При необходимости отредактируйте список услуг (SERVICES) и доступные часы (TIME_SLOTS).

3. ПОДКЛЮЧЕНИЕ GOOGLE ТАБЛИЦ (ОПЦИОНАЛЬНО)
- Если вы хотите, чтобы записи дублировались в Google Таблицу, положите файл ключа сервисного аккаунта под именем credentials.json в эту же папку.
- Если файл credentials.json отсутствует, бот будет работать без ошибок, сохраняя все записи в локальную базу данных bookings.db.

4. ЗАПУСК БОТА
- Выполните команду в терминале:
  python bot.py

5. ФУНКЦИИ БОТА
- Для клиентов: выбор услуги, выбор свободной даты и времени по кнопкам, защита от двойной записи, просмотр и самостоятельная отмена своих записей («📋 Мои записи»).
- Для администратора: мгновенные уведомления о новых записях и отменах, команда /admin для просмотра списка записей.
